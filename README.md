# My Favorite Superhero
**Title:** Spider-Man
**Genre:** Action, Adventure, Superhero
- I like *Spider-Man* because he’s a hero who started as an ordinary person but chose to do what’s right.  
He shows that **responsibility** and **courage** matter more than power.  
It’s not about having special abilities — it’s about using them to help others.
